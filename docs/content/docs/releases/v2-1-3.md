## Fixed

- **GitHub auto-fetch scheduler never ran.** The scheduler-lease table kept
  its legacy single-row schema (`CHECK (id = 1)`) while the GitHub auto-fetch
  scheduler leases row 2 — the insert failed on every cycle.
  `run_migrations` now rebuilds the table once (row 1 carries over), and the
  fresh-DB schema is multi-row directly.

## Added

- **`buz-manager rotate-jwt-key`** — in-place JWT key rotation with full
  re-encryption. Plan/apply model: the default run validates every stored
  blob and prints an inventory with zero writes; `--apply` snapshots the
  database, re-encrypts secrets, GitHub connection tokens, git-hook secrets,
  environment secret overrides, host credentials and encrypted job trigger
  params in one transaction, and roundtrips every new blob before
  committing. See [Key Rotation](../03-operations/key-rotation.md).

## Project

- The repository is now **public**.
